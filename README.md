# Meesho DICE Challenge 3.0 - UI Prototypes

?? [**Click Here for Live Interactive Demo**](https://meeshodice.vercel.app/)


This repository contains the front-end interactive UI prototypes developed for the Meesho DICE Challenge 3.0. 

## Overview
These prototypes demonstrate the proposed product levers to improve the Meesho creator commerce ecosystem:
1. **Acquisition:** Buyer-to-Creator onboarding funnel.
2. **Wallet & Sampling:** SplitPay integration and Trial SKU sampling.
3. **UGC on PDP:** Shoppable livestreams and skin-tone matched creator reviews.
4. **Storefront & Routines:** Creator bundles and AOV gamification thresholds.
5. **Retention:** Creator streaks, milestones, and AI-powered analytics.

## Tech Stack
- **HTML5 & CSS3**
- **Tailwind CSS** (via CDN)
- **Vanilla JavaScript** (Interactivity & state simulation)

## Deployment
These prototypes are designed to be deployed instantly on Vercel as a static site. The entry point is index.html.
